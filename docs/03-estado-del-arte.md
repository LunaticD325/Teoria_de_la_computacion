# Estado del Arte y Herramientas Existentes

En la teoría de lenguajes formales y autómatas existen herramientas consolidadas:

* **JFLAP (Java Formal Languages and Automata Package):** Herramienta educativa estándar para diseño y simulación de autómatas, conversión a ER y análisis sintáctico.
* **Motores de Expresiones Regulares (PCRE, Python `re`, V8):** Implementaciones optimizadas en lenguajes de programación que añaden extensiones como retro-referencias (*backreferences*), cambiando la clase de lenguaje reconocible.
* **Graphviz / Dot:** Motor de renderizado vectorial utilizado para la visualización gráfica de estados y transiciones.
