# Manual del Simulador Interactivo

El simulador interactivo desarrollado con **Flet** permite:
1. **Carga de Archivos `.jff`:** Importación directa de diagramas diseñados en JFLAP.
2. **Conversión ER a Autómata:** Procesamiento de expresiones regulares teóricas mediante el algoritmo de Thompson.
3. **Eliminación de Estados:** Obtención de expresiones regulares a partir de autómatas finitos.
4. **Validación de Cadenas:** Simulación paso a paso y verificación de cadenas contra los autómatas construidos.
